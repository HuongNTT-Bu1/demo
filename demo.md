# Demo

Đây là file Markdown minh họa các thành phần cơ bản: heading, bảng, danh sách, code block và link.

## Giới thiệu

Dự án demo này dùng để thử nghiệm các cú pháp Markdown.

## Tính năng

- Hỗ trợ heading nhiều cấp
- Hiển thị bảng dữ liệu
- Danh sách có thứ tự và không thứ tự
- Code block có highlight cú pháp
- Chèn liên kết ra ngoài

### Danh sách công việc

1. Khởi tạo project
2. Viết tài liệu
3. Viết code
4. Kiểm thử

## Bảng ví dụ

| Tên        | Loại      | Mô tả                  |
|------------|-----------|------------------------|
| README.md  | Tài liệu  | File giới thiệu dự án  |
| main.py    | Code      | File chạy chính        |
| test.py    | Test      | File kiểm thử          |
| config.yml | Cấu hình  | File cấu hình dự án    |
| utils.py   | Code      | Các hàm tiện ích       |
| CHANGELOG.md | Tài liệu | Lịch sử thay đổi      |

## Code block

```python
def hello(name):
    print(f"Xin chào, {name}!")

hello("Hương")
```
